# 物理シミュレーター

ブラウザで動くインタラクティブな2D物理シミュレーターです。外部ライブラリ不使用(バニラJavaScript + Canvas)。

## 使い方

`index.html` をブラウザで開くだけで動きます。ローカルサーバーを使う場合:

```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## シーン

| シーン | 内容 |
|---|---|
| ボール落下 | 重力・衝突・反発のデモ。クリックでボール追加 |
| 多重振り子 | 距離コンストレイントによる3連振り子(軌跡表示付き) |
| ニュートンのゆりかご | 運動量保存のデモ |
| 惑星軌道 | 万有引力による公転(軌道の軌跡表示) |
| ビリヤード | 白球をドラッグして弾くブレイクショット |
| バネ連結 | フックの法則によるバネのチェーンとソフトボディ風構造 |

## 操作

- **クリック(空きスペース)**: ボールを追加
- **ドラッグ**: 物体をつかんで動かす・投げる
- **スペースキー**: 一時停止 / 再生
- **Rキー**: 現在のシーンをリセット
- **スライダー**: 重力・反発係数・再生速度をリアルタイム調整
- **コマ送り**: 一時停止中に1コマずつ進める

## 物理エンジンの実装

`js/physics.js` に自前実装:

- セミインプリシット・オイラー法による積分(固定タイムステップ 1/240 秒)
- 円形剛体同士のインパルスベース衝突解決(反発係数・摩擦・めり込み位置補正)
- 距離コンストレイント(逐次インパルス法 + 位置投影、振り子・ロープ用)
- バネ(フックの法則 + 減衰)
- 万有引力(N体、惑星軌道シーン用)

## ファイル構成

```
index.html      エントリーポイント
style.css       スタイル
js/physics.js   物理エンジン(Body / World / コンストレイント / バネ)
js/presets.js   シーン定義
js/main.js      描画・UI・メインループ
```
