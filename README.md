# 物理シミュレーター

ブラウザで動くインタラクティブな2D物理シミュレーターです。外部ライブラリ不使用(バニラJavaScript + Canvas)。スマホのタッチ操作に対応しています。

**▶ デモ: https://hika1997.github.io/physics_simulator/**

## 使い方

上のURLをスマホ/PCのブラウザで開くだけ。ローカルで動かす場合は `index.html` を開くか:

```sh
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

## シーン

| シーン | 内容 |
|---|---|
| ボール落下 | 重力・衝突・反発のデモ。タップでボール追加 |
| 多重振り子 | 距離コンストレイントによる3連振り子(軌跡表示付き) |
| ニュートンのゆりかご | 運動量保存のデモ |
| 惑星軌道 | 万有引力による公転(軌道の軌跡表示) |
| ビリヤード | 白球をドラッグして弾くブレイクショット |
| 布シミュレーション | 粒子＋コンストレイント格子の布。風でなびく |
| ガルトンボード | 玉が釘に当たって二項分布の山を作る |
| 噴水 | パーティクルエミッター(最大500粒子超、空間ハッシュで高速化) |
| ロープ橋 | 吊り橋にボールを落として揺らす |
| 破壊球 | 重い鉄球でボールのピラミッドを崩す |
| バネ連結 | フックの法則によるバネのチェーンとソフトボディ風構造 |

## ツール

- **🖐 つかむ** — ドラッグで物体を動かす・投げる。空きスペースをタップでボール追加
- **➕ 追加** — タップした場所にボールを追加
- **🗑 削除** — タップ/なぞって物体を削除
- **📌 固定** — タップで物体を空間に固定/解除
- **🧲 引力 / 💥 斥力** — 押している間、指先に物体を引き寄せる/弾き飛ばす

## 設定(⚙ボタン / デスクトップは常時表示)

重力・**風**・反発係数・再生速度のスライダー、速度ベクトル表示、コマ送り。

キーボード: スペース=一時停止、R=リセット、V=速度ベクトル表示。

## 物理エンジンの実装

`js/physics.js` に自前実装:

- セミインプリシット・オイラー法による積分(固定タイムステップ 1/240 秒)
- 円形剛体同士のインパルスベース衝突解決(反発係数・摩擦・めり込み位置補正)
- 空間ハッシュによるブロードフェーズ(数百粒子でもリアルタイム動作)
- 距離コンストレイント(逐次インパルス法 + 位置投影、振り子・ロープ・布用)
- バネ(フックの法則 + 減衰)
- 万有引力(N体)、風、ポインタ引力/斥力
- パーティクルエミッター(寿命・生存数上限つき)

## ファイル構成

```
index.html      エントリーポイント
style.css       スタイル(モバイル対応)
js/physics.js   物理エンジン(Body / World / コンストレイント / バネ / エミッター)
js/presets.js   シーン定義
js/main.js      描画・UI・メインループ
```
